# 🎓 Student Performance Predictor

An interactive end-to-end Machine Learning web application built using Streamlit and Scikit-learn to forecast student academic performance based on study habits, attendance, and demographic factors.

## 🚀 Key Features
- **Predictive ML Pipeline:** Linear regression model calibrated on student academic features.
- **Dynamic User Interface:** Real-time form controls for instant prediction scoring.
- **Data Preprocessing:** Handles one-hot encoded variables and standard continuous inputs seamlessly.

## 🛠️ Built With
- **Python**
- **Streamlit** (Web Application Interface)
- **Scikit-learn** (Machine Learning Model)
- **Pandas & NumPy** (Data Processing)
- **Joblib** (Model Serialization)

## 💻 How to Run Locally
1. Clone the repository:
   ```bash
   git clone [https://github.com/muhadisa-a13y/student-performance-predictor.git](https://github.com/muhadisa-a13y/student-performance-predictor.git)
   cd student-performance-predictor

   Install dependencies:
   pip install streamlit scikit-learn pandas numpy joblib

   Run the application:
   streamlit run app.py
